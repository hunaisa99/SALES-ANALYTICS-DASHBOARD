# SALES-ANALYTICS-DASHBOARD


An interactive Sales Analytics Dashboard designed to visualize and analyze business performance through key sales KPIs and interactive charts.

## Dashboard Preview

![Sales Analytics Dashboard](./Capture.PNG)

## Key Features

- Total Revenue
- Total Quantity Sold
- Total Orders
- Average Order Value
- Total Customers
- Monthly Sales Trend
- Sales by Region
- Profit by Region
- Top Customers by Revenue
- Sales vs Cost by Product
- Sales by Item Category
- Quantity Sold by Product
- Orders Over Time

## Dashboard Filters

- Month
- Region
- Item Category

## Screenshot

The dashboard provides a comprehensive overview of sales performance and helps identify trends, profitable regions, high-performing products, and valuable customers.

## Technologies

- Microsoft Power BI / Data Visualization
- Data Analytics
- Interactive Dashboard Design
